# 🎓 د زده کونکو مدیریت سیستم (Student Management System)

دا یو بشپړ سافټویر دی چې د مکتب لپاره جوړ شوی — زده کونکي اضافه، ایډیټ، حذف او لیست کیدلی شي.

## 🛠️ کارول شوي ټکنالوژۍ
- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Backend:** Node.js + Express.js
- **Database:** SQLite (فایل: `school.db` په خپله جوړیږي)

## 📁 د فایلونو جوړښت
```
school-app/
├── server.js          ← Express سرور او API routes
├── database.js        ← د ډیټابیس اتصال او جدول جوړول
├── package.json        
├── school.db          ← ډیټابیس فایل (په خپله جوړیږي)
└── public/
    ├── index.html      ← اصلي پاڼه
    ├── style.css        ← ډیزاین
    └── script.js       ← Frontend منطق (fetch calls)
```

## 🚀 د چلولو ترتیب

### 1) Node.js نصب کړئ
که نصب نه دی، دلته یې ډاونلوډ کړئ: https://nodejs.org (نسخه 18 یا پورته)

### 2) Dependencies نصب کړئ
د پروژې فولډر ته ننوځئ او دا کمانډ وکاروئ:
```bash
cd school-app
npm install
```

### 3) سرور پیل کړئ
```bash
npm start
```

### 4) پروګرام خلاص کړئ
په براوزر کې لاړ شئ:
```
http://localhost:3000
```

## ✅ فیچرونه
- ➕ نوی زده کونکی اضافه کول (نوم، د پلار نوم، ټولګی، عمر، تلیفون، پته)
- ✏️ د زده کونکي معلومات ایډیټ کول
- ❌ زده کونکی حذف کول
- 🔍 د نوم/ټولګي په اساس لټون
- 💾 ټول معلومات په SQLite ډیټابیس کې ذخیره کیږي (سرور بند شي هم معلومات نه له منځه ځي)

## 🔌 API Routes (که وغواړئ نور سیستمونه ورسره وصل کړئ)
| Method | Route              | کار                          |
|--------|--------------------|-------------------------------|
| GET    | /api/students      | ټول زده کونکي راوړل          |
| GET    | /api/students/:id  | یو ځانګړی زده کونکی راوړل     |
| POST   | /api/students      | نوی زده کونکی اضافه کول        |
| PUT    | /api/students/:id  | زده کونکي معلومات بدلول        |
| DELETE | /api/students/:id  | زده کونکی حذف کول              |
